# MGT-665-Final-Project

This repository contains the code for the final project for Northwood University Devos Graduate School's MGT 665 course. The project uses the Titanic dataset from Kaggle to determine similarities in surviving passengers and also compares the effectiveness of three models, Logistic Regression, Decision Tree, and KNN. This repository contains the raw code for the project as Jupyter Notebook, the final project paper as a Word document, and the dataset used as a .csv file. This project was the combined work of Long Lin and Ian McCormick.
